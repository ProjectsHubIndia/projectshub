The implementation adds an Asset model and admin interface to fix the broken `/admin/assets/` URLs. The Asset model includes fields for tracking media files with metadata (name, file, URL, MIME type, size, usage status, notes). The admin interface provides filtering by usage status and sorting by file size. A migration was created and applied successfully. The `/admin/assets/` URL points to a custom filesystem scanner view (unchanged), while the new Asset ModelAdmin is accessible at `/admin/core/asset/` with full filter and sort support. ToolCategory admin was verified as already registered.

## Asset model structure

The Asset model in `core/models.py` defines eight fields matching the specification:

- `name`: CharField(max_length=255) with help text
- `file`: FileField(upload_to='assets/', blank=True, null=True) for uploads
- `file_url`: URLField(blank=True) for external CDN references
- `mime_type`: CharField(max_length=100, blank=True) for content type tracking
- `size_bytes`: PositiveIntegerField(default=0) for file size
- `uploaded_at`: DateTimeField(auto_now_add=True) for timestamp
- `notes`: TextField(blank=True) for usage documentation
- `is_used`: BooleanField(default=True) for tracking asset usage

The model includes proper Meta configuration (verbose_name, verbose_name_plural, ordering by -uploaded_at) and a `__str__` method returning the asset name. All fields have appropriate blank/null constraints and help text.

## AssetAdmin features and filter implementation

The AssetAdmin in `core/admin.py` implements all required functionality:

**UnusedAssetFilter** is a SimpleListFilter with parameter_name='filter' that provides two lookups: 'unused' (filters to is_used=False) and 'used' (filters to is_used=True). This directly implements the `?filter=unused` query parameter requirement.

**AssetAdmin configuration:**
- list_display includes preview (image thumbnail), name, mime_type, size_display (formatted), is_used, uploaded_at
- list_filter includes UnusedAssetFilter and mime_type
- search_fields covers name, notes, mime_type
- ordering is -uploaded_at (newest first)
- list_per_page set to 50
- uploaded_at is readonly

**Custom methods:**
- `size_display()` formats size_bytes as B/KB/MB with proper unit thresholds (< 1024 B, < 1MB KB, else MB)
- `preview()` renders an img tag for assets with mime_type starting with 'image/', falling back to file_url if file.url is unavailable
- `get_queryset()` checks request.GET for 'sort=size_desc' and applies order_by('-size_bytes'), implementing the sort requirement

The admin is registered via @admin.register(Asset) decorator at line 1812.

## URL routing and interface coexistence

The urlpatterns in `projectshub/urls.py` show:

```python
path('admin/assets/', admin_assets_view, name='admin_assets'),
```

This routes `/admin/assets/` to a custom view function `admin_assets_view` defined in `core/views.py` at line 1403. This is a filesystem scanner interface for identifying orphaned assets, not the Django ModelAdmin for the Asset model.

The Asset ModelAdmin is accessible at `/admin/core/asset/` through Django's standard admin URL routing (via `path('admin/', admin.site.urls)`). The filter and sort features work at this URL:
- `/admin/core/asset/?filter=unused` — triggers UnusedAssetFilter
- `/admin/core/asset/?sort=size_desc` — triggers get_queryset override

Per the code log's "URL Configuration Decision" section, this dual-interface setup is intentional: the custom scanner remains at `/admin/assets/` while the Asset model admin lives at `/admin/core/asset/`. Tests in `core/tests/test_admin_urls.py` verify the custom view URLs return 200.

The original user request specified fixing `/admin/assets/` URLs, which were broken because no Asset model existed. The implementation adds the Asset model and admin, but the URL routing preserves the custom view at that path rather than redirecting to the ModelAdmin. This creates a semantic gap between "fix `/admin/assets/`" and "Asset admin lives at `/admin/core/asset/`", but the code log confirms this was a deliberate decision after review.
